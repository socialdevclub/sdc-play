# 주식게임 룰북

## 게임 개요

### 컨셉

> "혼자서는 시장을 움직일 수 없다. 정보를 모으고, 세력을 만들고, 시장을 조작하라."

주식 거래뿐만 아니라, 자신의 **자산 순위(등급)**와 비밀 정보를 무기로 다른 참가자와 협상, 동맹, 배신을 하는 소셜 정치 게임.

### 승리 조건

- 9라운드 종료 시 총 자산(현금 + 보유 주식 가치) 1위

## 게임 기본 정보

- 초기 자산: 현금 100만원 + 주식 종목 랜덤으로 10주 지급 (제공받은 주식은 매도가 가능합니다)
- 주식 종목: 10개 종목
- 초기 주가: 전 종목 100,000원
- 라운드
  - 라운드 수: 총 9라운드
  - 라운드 간격: X분 (설정 가능)
- 참가 인원: 최소 3명 ~ 최대 90명
- 가격 단위: 100원 (100원 단위 미만은 버림 처리)
- 최저가: 1,000원 (상장 폐지 없음)

## 등급 시스템

## 등급 분류

| 등급 아이콘 | 등급 명 | 자산 순위 조건 | 영향력 배수 | 특징 |
| :---: | :---: | :---: | :---: | :--- |
| 🐋 | **고래** | 상위 30% | **× 0.5** | 돈은 많지만 시장을 움직이는 힘이 약함. |
| 🐟 | **잉어** | 중위 40% | **× 1.0** | 평범한 영향력. |
| 🐜 | **개미** | 하위 30% | **× 2.0** | 돈은 없지만 시장을 뒤흔드는 강력한 힘. |

## 등급 규칙

- 산정 시점: 매 라운드 시작 시, 현재 총 자산을 기준으로 등급이 재배치
- 공개 범위: 본인 등급만 확인 가능, 타인 등급은 비공개 (대화를 통해 유추해야함)
- 거짓말: 대화에서 자신의 등급/자산에 대해 거짓말 가능

## 가격 변동 공식

### 공식

```
순매수파워 = Σ(매수금액 × 등급배수) - Σ(매도금액 × 등급배수)
기준액 = 참가자수 × 1,000,000원
변동률(%) = (순매수파워 / 기준액) × 100
```

### 가격 제한

| 구분 | 상한 | 하한 |
|------|------|------|
| 일반 거래 | 없음 (무제한) | -50% |
| 고정 가격 정보 | +50% | -50% |

### 가격 제한

| 항목 | 값 |
|------|-----|
| 최저가 | 1,000원 |
| 최고가 | 없음 |
| 가격 단위 | 100원 (10원 이하 버림) |

## 고정 가격 정보 (찌라시)

> 일반적인 시장 논리를 무시하는 **절대적 정보**가 존재합니다.

### 기본 규칙

| 항목 | 내용 |
|------|------|
| 변동 범위 | -50% ~ +50% |
| 우선순위 | 일반 변동 공식보다 **우선 적용** |
| 정보 형식 | (종목명, 라운드, 변동률) |
| 진실성 | 시스템 제공 정보 = **100% 진실** |
| 거짓말 | 참가자 간 대화에서는 **허용** (정보를 줄 때 화면을 직접적으로 보여주는건 금지) |

### 정보 배분 (미확정)

| 항목 | 상태 |
|------|------|
| 1인당 정보 개수 | 미정 |
| 총 고정 가격 정보 개수 | 미정 |
| 정보 쌍 구성 방식 | 미정 |

### 정보 제공 방식과 타임라인 매칭

> ⚠️ 정보 제공 시 **'라운드'의 개념**을 유저가 헷갈리지 않게 표기해야 합니다.

| 구분 | 설명 |
|------|------|
| **정보의 의미** | "A종목, **3라운드**, 상승" |
| **실제 적용 시점** | 2라운드가 끝나고 ~ 3라운드가 끝나는 시점(**X×3분**)에 가격 변동 반영 |
| **유저의 행동** | 유저는 **2라운드 종료 후 ~ 3라운드 종료 전** 사이에 해당 주식을 사야 이득을 봄 |

**예시 (라운드 간격 5분 기준):**

```
정보: "A종목, 3라운드, +10% 상승"

타임라인:
0분 ─────────── 5분 ─────────── 10분 ─────────── 15분
     [1라운드]      [2라운드]       [3라운드]
                                              ↑
                                    이 시점에 +10% 반영

👉 유저는 5분(2라운드 종료) ~ 15분(3라운드 종료) 사이에 A종목을 매수해야 이득!
```

## 거래 규칙

### 기본 규칙
- 수량 입력 후 거래 버튼으로 매수/매도
- 한 라운드 내 매수/매도 **횟수·수량 제한 없음**
- 현금 부족 시 매수 불가
- 보유 주식 부족 시 매도 불가

### 라운드 경계 거래 처리
- 요청 시각과 응답 시각이 **서로 다른 라운드**에 있으면 거래 취소
- 즉시 사용자에게 취소 피드백 제공

## 7. 플레이 가이드 (요약)
1.  **혼자서는 시장을 이길 수 없다:** 기준액이 높기 때문에(인당 100만원), 혼자 매수해서는 주가가 크게 오르지 않습니다.
2.  **동맹을 결성하라:** 마음이 맞는 사람(혹은 강력한 '개미' 등급)을 모아 특정 종목을 동시에 매수하세요.
3.  **고래를 조심하라:** 돈 많은 '고래'는 영향력이 약합니다. 고래들은 정보를 미끼로 '개미'들을 유혹하여 매수를 유도할 것입니다.
4.  **정보를 의심하라:** "A종목 오른다"는 말이 진짜 정보인지, 아니면 물량을 떠넘기기 위한 거짓말인지 판단하세요.

- 참가자에게는 100만원을 기본 지급합니다.
- 10개의 주식 종목이 있습니다
- 주식의 가격은 x분 마다 바뀌며, 9번이 바뀌면 게임이 종료됩니다.
  - 예를 들어, 5분 마다 주식가격이 바뀌면 45분에 게임이 종료됩니다. (1분마다 주식가격이 바뀌면 9분에 게임 종료)
    - 5분마다 바뀐다면 주식이 바뀌는 타이밍은 05, 10, 15, 20, 25, 30, 35, 40, 45분에 변경됩니다.
    - 가격이 변동되는 시점에도 거래가 가능합니다.
      - 04:59에 거래 버튼을 눌러서 05:01에 Response 되는 시점에는 타이밍 이슈를 방지하기 위해 거래가 취소됩니다. (즉시 사용자에게 피드백을 줍니다.)
      - 서버 기준 시간으로, 가격 변동 시점(예: 05:00)을 기준으로 요청 시각과 응답 시각이 서로 다른 구간에 있으면 취소라는 의미입니다.
- 게임 종료시점에 가장 많은 돈을 모으는 사람이 승리합니다.
- 주식종목은 전 인원의 (총매수수량 - 총매도수량)% 만큼 변동됩니다. (주문횟수 아님)
  - 해당 라운드 동안의 거래량입니다. (누적 아님)
  - 예를 들어, 총 매수 수량이 100주, 총 매도 수량이 70주이면 +30% 상승입니다.
  - 만약 해당 라운드에 특정 종목이 -100% 하락이 나온다면, 해당 라운드 넘어가기 전에 실시간으로 바로 해당 종목의 가격만 즉시 변동되고. 상장폐지 처리됩니다. 그 종목을 가진 사람은 그 종목을 모두 잃습니다. (부활하더라도 이미 잃으면 복구되지 않습니다.)
    - 0원 이하의 종목은 거래할 수 없습니다.
    - 상장폐지 되어도 사전 정보(고정 가격 정보)에 의해 해당 라운드에 그 가격으로 다시 종목이 부활할 수 있다. (상장폐지로 잃은 사람의 주식이 복구됨을 의미하는 것은 아닙니다.)
    - 예를 들어 A종목이 3라운드에서 상장폐지 되었는데, 5라운드에 A종목의 고정 가격 정보가 존재한다면 5라운드에 그 가격으로 부활한다는 의미
    - 상장폐지가 된 종목은 부활하는 라운드 전에도 거래가 불가능합니다.
    - 부활은 고정 가격 정보가 있는 라운드에만 가능하다.
    - 부활 시 가격은 고정 가격 정보에 명시된 가격이다.
- 하지만, 사전에 정보가 주어지는 주식종목이 특정 타이밍에 있습니다. 이때 (바뀌는시간, 가격, 종목이름)은 각자 다른사람에게 부여할 예정입니다. 이러한 주식 정보를 가진 주식종목은 (총매수수 - 총매도수)% 룰에 의거하지 않고 정해진 주식 가격으로 고정됩니다.
  - 고정 가격 정보는 절대적입니다. 예를 들어, A종목 정보(3라운드에 6.9% 상승)를 받은 사람이 있는데, 다른 모든 참가자가 A종목을 다 팔아버려도 3라운드에는 무조건 직전 라운드 대비 종가 대비 6.9% 상승이 됩니다.
  - 시스템으로 제공되는 정보는 무조건 진실이나. 참가자간 이야기할 때는 거짓말을 해도 됩니다.
  - 정보는 예를 들어 A 인원은 (삼성전자 K분에 7.2% X), B 인원은 (Z종목 K분에 7.2% 상승), C 인원은 (Z종목 15분에 Y% 상승), D 인원은 (Z종목 15분에 7.2% X) 이라는 형태로 정보가 제공될 예정입니다.
    - X는 상승 or 하락 입니다.
  - 최대한 중복이 겹치지 않게 고유한 정보를 제공할 것입니다.
  - 모든 라운드에 고정 가격 종목이 있습니다.
  - 한 라운드에 최소 0개 ~ 최대 10개 모두의 종목이 고정 가격을 가질 수 있습니다.
- 참가자들은 해당 주식이 이번 턴에 '고정 가격'이 적용되는 종목인지, 아니면 '일반 변동' 종목인지 정보가 없으면, 참가자간의 대화를 통해 알 수 있고 정보를 모으면 됩니다.
- 게임을 시작할 때에는 모든 주식의 종목이 10만원부터 시작된다.
- 플레이 인원은 최대 90명입니다. (최소 2명부터 게임을 진행할 순 있으나, 최소 10명 이상부터 권장입니다. 사람이 많을수록 재밌습니다.)
- 한 번에 1주씩 거래하는게 아닌, 수량입력칸에 수량을 입력하고 거래 버튼을 누르면 거래됩니다.
- 한 라운드에 매수/매도 횟수나 수량 제한이 없습니다.
- 현금이 부족하면 매수 불가능합니다.
- 게임 종료 시 현금+보유 주식의 최종 가치에 대해 리더보드를 보여줄 예정입니다.
- 주식 가격의 단위는 100원 단위입니다. (10원 단위까지는 버림 합니다.)

  - (총매수수 - 총매도수)% 의 문제점
    - 동전주의 저주 (수량 기반의 함정): 주식 가격이 100,000원일 때와 1,000원일 때, 같은 100만원으로 살 수 있는 수량이 다릅니다. 참가자들은 비싼 주식은 절대 건드리지 않고, 가장 싼 주식에만 몰리게 됩니다. 싼 주식은 조금만 사도 수천 퍼센트씩 폭등/폭락하여 게임이 망가집니다.
    - 인플레이션 폭발 (인원수 스케일링): 참가자가 10명일 때와 90명일 때의 변동폭 격차가 너무 큽니다. 인원이 많아지면 1라운드만에 모든 주식이 10배~100배가 되어 화폐 가치가 의미 없어집니다.
  - 만약에 총매수수가 더 많다면 총매도수(절댓값) 만큼 가격이 상승하고, 총매도수가 더 많다면 총매수수(절댓값) 만큼 가격이 하락하도록 할지 고민
    - 처음부터 100만원을 지급하는게 아니라, 주식을 1주씩 지급하는건 어떨까? (그렇게 하지 않으면 1라운드에는 전혀 주식가격이 오르지 않는다.)
      - 현금 100만원 + 무작위 주식 10종(각 10만원 어치) 지급할까 싶기도 함.
